# داشبورد هوشمند امکان‌سنجی پروژه گردشگری ثمین چابکسر

داشبورد تعاملی سه‌سناریویی برای بررسی سرمایه‌گذاری، جریان‌های نقدی، نرخ بازده داخلی (IRR)، خالص ارزش فعلی (NPV)، دوره بازگشت و تحلیل حساسیت. طراحی راست‌به‌چپ، فونت Vazirmatn، تم روشن/تیره و کارت‌های مدیریتی واکنش‌گرا.

## انتشار نسخه HTML

نسخه اجرایی یک فایل مستقل HTML است و برای اجرا نیاز به ساخت (Build) یا نصب وابستگی ندارد. فایل `Chaboksar_Investment_Dashboard_Updated.html` را در ریشه مخزن با نام **`index.html`** بارگذاری کنید. پس از بارگذاری، برای فعال‌سازی وب‌سایت از **Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/ (root)` → Save** استفاده کنید. نشانی پیشنهادی سایت: https://hrtorabii-404.github.io/IdehPardaz/

> وضعیت فعلی: فایل HTML هنوز در مخزن بارگذاری نشده است؛ این README به‌تنهایی وب‌سایت را راه‌اندازی نمی‌کند.

## ملاحظات انتشار عمومی

خود HTML شامل مفروضات اقتصادی و ارقام سه سناریو است؛ با انتشار `index.html`، این داده‌ها نیز عمومی می‌شوند. برای انتشار داشبورد ضرورتی ندارد فایل Excel اصلی یا مستندات داخلی را بارگذاری کنید. فونت Vazirmatn از Google Fonts فراخوانی می‌شود و در صورت نبود اتصال، فونت جایگزین نمایش داده می‌شود.
